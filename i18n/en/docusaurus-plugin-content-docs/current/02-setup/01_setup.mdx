# Setup

## 1) Requirements
- **Minimum SDK**: 26 (Android 8.0)
- **Target SDK**: 36
- **Supported ABIs**: arm64-v8a, armeabi-v7a

### Recommended Specifications

| Item | Recommended | Notes |
|------|----------|------|
| Android | API 26 (8.0) or higher | |
| CPU | ARM 64-bit (ARMv8) | 8 cores or more |
| RAM | 6 GB or more | |
| GPU | OpenCL 1.2 + `cl_khr_fp16` | Required for GPU inference |
| GPU performance | FP32 ~300 GFLOPS or higher | Reference: Galaxy Tab S9 FE+ (Mali-G68 MP5, ~300 GFLOPS) |

:::warning Pre-validation required
Catalog specifications alone cannot guarantee that the SDK will work correctly.

- **Same numbers, different results**: Even with GPUs of similar performance (GFLOPS), inference time has been observed to differ by 2–3x depending on the vendor (Mali/Adreno/PowerVR).
- **CPU matters more than GPU**: About two-thirds of the SDK's total processing is CPU work. Judging by GPU specs alone will not predict real-world performance.
- **Driver compatibility**: Some devices fail to initialize the GPU delegate due to OpenCL driver bugs. Even on the same model, behavior can differ depending on the OS version.
- **Thermal throttling**: During extended operation, heat lowers CPU/GPU clocks and degrades performance.
- **Discovering problems after deployment is costly**: In mass-deployment environments such as kiosks and TVs, on-site response costs arise when problems occur. A 5-minute benchmark up front removes this risk.

**Pre-validation with the benchmark app is required before adopting a new device.**

| Item | Pass criteria |
|------|----------|
| OpenCL support | OpenCL 1.2+ & `cl_khr_fp16` |
| TFLite GPU inference | Initialization succeeds |
| Inference time | &lt;50 ms (excluding pre/post-processing) |
| FPS (while speaking) | Sustained 24 fps or higher |
| 5 minutes of continuous operation | Stable memory, temperature &lt;45°C |
:::

### Resources

The SDK requires a video file (`.mp4`) and a face model file (`.npz`).
Place these files in the `assets` folder (`src/main/assets`), then call `ResourceManager.init()` to copy them to the cache and initialize.

```kotlin
import io.klleon.ondevice.ResourceManager

val resourceManager = ResourceManager()

ResourceManager.init(
    context = this,
    mp4FileName = "loop_sample.mp4",
    npzFileName = "loop_sample.npz",
    avatarId = "character_001",
    onSuccess = {
        // Resources ready — play() can now be called
    },
    onError = { error ->
        Log.e("Setup", "Failed to prepare resources", error)
    }
)
```

:::info
Internal paths are configured automatically once `init()` completes.
The `onSuccess` callback of `init()` must be invoked before you call `play()`.
:::

## 2) Android Configuration

```kotlin
android {
    compileSdk = 36

    defaultConfig {
        minSdk = 26
        targetSdk = 36
    }

    packaging {
        jniLibs {
            pickFirsts += "**/libc++_shared.so"
        }
    }
}
```

## 3) Gradle Dependencies

Add the following dependencies to your app-level `build.gradle.kts`:

```kotlin
dependencies {
    // SDK
    implementation("io.klleon:ondevice-sdk:0.13.0")

    // Coroutines (required by the SDK)
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.9.0")
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.9.0")
}
```

:::info Bundled libraries
The SDK AAR includes the following libraries:
- OkHttp, Okio, Retrofit
- Jackson (Core, Module)
- TensorFlow Lite
- OpenCV
- PyTorch Mobile
- Oboe
- ONNX Runtime
- Agora RTC

If your app uses a library that depends on OkHttp or Okio (for example, Coil), a version conflict may occur. In that case, exclude the corresponding groups from `RuntimeClasspath`:
```kotlin
configurations.matching { it.name.contains("RuntimeClasspath", ignoreCase = true) }.configureEach {
    exclude(group = "com.squareup.okhttp3")
    exclude(group = "com.squareup.okio")
}
```
:::

## 4) ProGuard / R8

The SDK AAR includes the required ProGuard/R8 rules, so **no additional configuration is needed.**

If you encounter an `UnsatisfiedLinkError`, check the `jniLibs.pickFirsts` setting in the Android configuration above.
