# Intro

# Klleon Ondevice SDK

![Version](https://img.shields.io/badge/version-0.12.0-blue.svg)

The Klleon Ondevice SDK is a powerful SDK that provides on-device AI capabilities along with video processing and real-time messaging. With this SDK, you can easily integrate chat features that let users communicate with AI-powered avatars in real time into your application.

## Key Features

### Video Processing
- AI video playback and lip sync
- High-performance on-device AI processing
- Video pause/resume control

### Speech Audio
- Cached speech — play pre-prepared PCM instantly without a server round trip (v0.12.0+)
- Non-streaming playback eliminates mid-speech dropouts (default in v0.12.0+)

### Real-time Messaging
- WebSocket-based real-time communication
- Message sending, echo, and speech interruption
- State management

### Speech Recognition
- Low-latency microphone recording
- Tap-to-talk speech recognition
- Automatic USB microphone detection and switching

### Android TV Support
- 270-degree rotated rendering
- TV remote key mapping
- TV focus UI optimization
