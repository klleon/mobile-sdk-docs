# はじめに

## 事前要件

Klleon Ondevice SDK を使用する前に、次の準備が必要です。

1.  **Kleon Studio アカウント**: SDK の機能を利用するには [Kleon Studio](https://www.studio.klleon.io/) のアカウントが必要です。アカウントがない場合は、まずご登録ください。
2.  **SDK キーの発行**: ドメイン登録後、そのドメインで使用する固有の `sdk_key` が発行されます。このキーは SDK の初期化に必要です。
3.  **アバター ID**: 使用する AI アバターの `avatarId` が必要です。

## 権限

### AndroidManifest.xml

`AndroidManifest.xml` に必要な権限を追加してください。

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
```

### コードでの権限処理

```kotlin
class MainActivity : ComponentActivity() {
    private val requiredPermissions = arrayOf(
        Manifest.permission.RECORD_AUDIO
    )

    private val permissionLauncher = registerForActivityResult(
        ActivityResultContracts.RequestMultiplePermissions()
    ) { permissions ->
        handlePermissionResults(permissions)
    }

    private fun checkPermissions(): Boolean {
        return requiredPermissions.all { permission ->
            ContextCompat.checkSelfPermission(this, permission) == PackageManager.PERMISSION_GRANTED
        }
    }

    private fun requestPermissions() {
        val permissionsToRequest = requiredPermissions.filter { permission ->
            ContextCompat.checkSelfPermission(this, permission) != PackageManager.PERMISSION_GRANTED
        }.toTypedArray()

        if (permissionsToRequest.isNotEmpty()) {
            permissionLauncher.launch(permissionsToRequest)
        }
    }

    private fun handlePermissionResults(permissions: Map<String, Boolean>) {
        val deniedPermissions = permissions.filter { !it.value }.keys

        if (deniedPermissions.isEmpty()) {
            Log.d("MainActivity", "すべての権限が許可されました")
            initializeApp()
        } else {
            Log.w("MainActivity", "権限が拒否されました: $deniedPermissions")
            // 拒否された権限の処理
        }
    }
}
```

## SDK の初期化

### 基本設定

```kotlin
import io.klleon.ondevice.KlleonOndeviceSdk
import io.klleon.ondevice.ResourceManager
import io.klleon.ondevice.render.KlleonSdkView

// アプリ全体で単一インスタンスを共有します
object SdkConfig {
    val sdk = KlleonOndeviceSdk()
}

class MainActivity : ComponentActivity() {
    private val klleonOndeviceSdk = SdkConfig.sdk
    private val resourceManager = ResourceManager()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        if (checkPermissions()) {
            initializeApp()
        } else {
            requestPermissions()
        }
    }

    private fun initializeApp() {
        setContent {
            OndeviceSampleTheme {
                Surface(
                    modifier = Modifier.fillMaxSize(),
                    color = MaterialTheme.colorScheme.background
                ) {
                    WorkerScreen(klleonOndeviceSdk = klleonOndeviceSdk)
                }
            }
        }

        // リソースの初期化（キャッシュへのコピー + YUV 変換 + メモリ読み込み）
        resourceManager.init(
            context = this,
            mp4FileName = "loop_sample.mp4",
            npzFileName = "loop_sample.npz",
            styleFileName = "loop_sample.style",
            avatarId = "character_001",
            onSuccess = {
                // リソースの準備完了 — play() を呼び出せます
            },
            onError = { error ->
                Log.e("MainActivity", "リソースの準備に失敗しました", error)
            }
        )
    }
}
```

### SDK の開始（play）

v0.8.0 から `voiceRecognitionMode` のデフォルトは `ALWAYS_ON`、`sttMode` のデフォルトは `STT_ONLY` です。追加の設定なしに `play()` を呼び出すだけでマイクセッションが自動的に開始され、STT の結果は `sdkState` の `STT_RESULT` chat_type で通知されます。

```kotlin
// play() は suspend 関数のため、コルーチンから呼び出します
CoroutineScope(Dispatchers.IO).launch {
    klleonOndeviceSdk.play(
        context = this@Activity,               // Context
        klleonSdkViewInstance = sdkView,       // KlleonSdkView インスタンス
        sdkKey = "YOUR_SDK_KEY",               // SDK キー
        avatarId = "character_001",            // アバター ID
        language = "ko_kr",                    // 言語（ko_kr, en_us, ja_jp）
        // sttMode = SttMode.STT_ONLY,         // v0.8.0+ のデフォルト（省略可）
        // useMelSpectrogram = false,          // v0.12.0+ のデフォルト（省略可）
    )
}
```

**パラメータ:**
| パラメータ | 型 | 必須 | 説明 |
|---------|------|------|------|
| `context` | Context | O | 現在のコンテキスト |
| `klleonSdkViewInstance` | KlleonSdkView? | O | レンダリングビューのインスタンス |
| `sdkKey` | String | O | SDK 認証キー |
| `avatarId` | String | O | AI アバター ID |
| `language` | String | O | 言語コード（`ko_kr`, `en_us`, `ja_jp`） |
| `sttMode` | SttMode | X | STT 結果の通知モード（v0.8.0+ デフォルト `STT_ONLY`） |
| `useMelSpectrogram` | Boolean | X | リップシンクのパイプラインモード（v0.12.0+ デフォルト `false`）。`true` の場合、キャッシュ発話 API を利用できます |
