# Intro

# Klleon Ondevice SDK

![Version](https://img.shields.io/badge/version-0.12.0-blue.svg)

Klleon Ondevice SDK は、ビデオ処理とリアルタイムメッセージングに加えて、オンデバイス AI 機能を提供する強力な SDK です。この SDK を使用すると、AI アバターとリアルタイムでやり取りするチャット機能をアプリケーションに簡単に統合できます。

## 主な機能

### ビデオ処理
- AI ビデオ再生およびリップシンク
- 高性能なオンデバイス AI 処理
- ビデオの一時停止/再開制御

### 発話オーディオ
- キャッシュ発話 — あらかじめ用意した PCM をサーバー往復なしで即座に発話します（v0.12.0+）
- ノンストリーミング再生により発話途中の途切れを解消します（v0.12.0+ デフォルト）

### リアルタイムメッセージング
- WebSocket ベースのリアルタイム通信
- メッセージ送信、エコー、発話中断機能
- 状態管理

### 音声認識
- 低遅延のマイク録音
- タップして話す方式の音声認識
- USB マイクの自動検出と切り替え

### Android TV 対応
- 270 度回転レンダリング
- TV リモコンのキーマッピング
- TV フォーカス UI の最適化
